# A1-1_Prompt_Manager

# 나만의 프롬프트 관리 프로그램

Python 콘솔에서 다양한 프롬프트를 등록하고 관리할 수 있는 프로그램입니다.

프롬프트를 카테고리별로 분류하고, 검색·상세 조회·즐겨찾기 기능을 통해 필요한 프롬프트를 쉽게 관리할 수 있습니다.

보너스 기능으로 JSON 파일을 이용한 데이터 저장 및 불러오기와 Markdown 파일 내보내기 기능을 구현했습니다.

---

## 실행 환경

- Python 3.10 이상
- 외부 라이브러리 없이 Python 기본 라이브러리만 사용
- 콘솔 기반 프로그램

---

## 실행 방법

프로젝트 폴더에서 터미널을 열고 다음 명령어를 실행합니다.

```bash
python prompt_manager.py
```

환경에 따라 다음 명령어를 사용할 수도 있습니다.

```bash
python3 prompt_manager.py
```

---

## 주요 기능

### 1. 프롬프트 추가

새로운 프롬프트를 등록할 수 있습니다.

입력 항목:

- 제목
- 내용
- 카테고리

제목이나 내용이 비어 있으면 다시 입력하도록 안내합니다.

카테고리는 기존 목록에서 선택하거나 `직접 입력`을 선택하여 새로운 카테고리를 만들 수 있습니다.

---

### 2. 프롬프트 목록

등록된 전체 프롬프트를 확인할 수 있습니다.

각 프롬프트에는 다음 정보가 표시됩니다.

- 번호
- 카테고리
- 제목
- 즐겨찾기 여부 ⭐

---

### 3. 카테고리별 조회

카테고리를 선택하면 해당 카테고리에 포함된 프롬프트만 확인할 수 있습니다.

사용자가 직접 만든 카테고리도 자동으로 조회 목록에 포함됩니다.

---

### 4. 프롬프트 검색

검색어를 입력하여 프롬프트를 찾을 수 있습니다.

검색 범위:

- 프롬프트 제목
- 프롬프트 내용

검색 결과가 없으면 별도의 안내 메시지를 출력합니다.

---

### 5. 프롬프트 상세 보기

프롬프트 번호를 선택하면 전체 정보를 확인할 수 있습니다.

표시 정보:

- 제목
- 카테고리
- 즐겨찾기 상태
- 프롬프트 전체 내용

잘못된 번호를 입력한 경우 다시 입력할 수 있도록 처리했습니다.

---

### 6. 즐겨찾기 관리

프롬프트 번호를 선택하여 즐겨찾기를 추가하거나 해제할 수 있습니다.

```text
일반 → ⭐ 즐겨찾기
⭐ 즐겨찾기 → 일반
```

즐겨찾기 상태는 JSON 파일에 저장됩니다.

---

### 7. 즐겨찾기 목록

즐겨찾기로 설정된 프롬프트만 따로 확인할 수 있습니다.

---

### 8. Markdown 내보내기

등록된 전체 프롬프트를 카테고리별로 정리하여 Markdown 파일로 내보낼 수 있습니다.

메뉴에서 `Markdown 내보내기`를 선택하면 `exports` 폴더가 자동으로 생성됩니다.

생성되는 파일:

```text
exports/prompts_export.md
```

---

## 데이터 저장

프로그램 데이터는 다음 파일에 저장됩니다.

```text
prompts.json
```

프로그램 실행 시 `prompts.json` 파일이 존재하면 저장된 데이터를 자동으로 불러옵니다.

파일이 존재하지 않는 경우 프로그램에 등록된 기본 프롬프트 데이터를 사용합니다.

프롬프트를 추가하거나 즐겨찾기 상태를 변경하면 JSON 파일에 자동으로 저장됩니다.

따라서 프로그램을 종료한 후 다시 실행해도 기존 데이터가 유지됩니다.

---

## 기본 프롬프트 데이터

프로그램 최초 실행 시 기본 프롬프트가 등록되어 있습니다.

예시 카테고리:

- 텍스트 생성
- 이미지 생성
- 페르소나

---

## 카테고리

기본으로 제공되는 카테고리는 다음과 같습니다.

- 텍스트 생성
- 이미지 생성
- 영상 생성
- 페르소나
- 자동화
- 기타
- 직접 입력

`직접 입력`을 선택하면 사용자가 원하는 새로운 카테고리를 만들 수 있습니다.

## 메뉴 구성

```text
=============================================
 나만의 프롬프트 관리
=============================================
1. 프롬프트 추가
2. 프롬프트 목록
3. 카테고리별 조회
4. 프롬프트 검색
5. 프롬프트 상세 보기
6. 즐겨찾기 관리
7. 즐겨찾기 목록
8. Markdown 내보내기
---------------------------------------------
0. 프로그램 종료
=============================================
```

기능 실행 후에는 다음 선택지를 이용할 수 있습니다.

```text
[M] 메인 메뉴  |  [0] 프로그램 종료
```

프롬프트 추가 기능은 등록이 완료되면 자동으로 메인 메뉴로 돌아갑니다.

## 프로젝트 구조

```text
A1-1_Prompt_Manager/
├── prompt_manager.py
├── prompts.json
├── README.md
└── exports/
    └── prompts_export.md
```

### 파일 설명

- `prompt_manager.py`  
  프롬프트 관리 프로그램의 메인 Python 파일

- `prompts.json`  
  프롬프트와 즐겨찾기 상태를 저장하는 데이터 파일

- `README.md`  
  프로젝트 설명 및 실행 방법

- `exports/prompts_export.md`  
  프로그램에서 Markdown 내보내기를 실행했을 때 생성되는 파일

## Git / GitHub

프로젝트는 Git을 이용하여 기능 단위로 변경 이력을 관리했습니다.

주요 Git 작업:

- Git 저장소 초기화
- 기능별 커밋
- 별도 브랜치에서 프롬프트 목록 기능 구현
- `main` 브랜치로 병합
- GitHub 원격 저장소 업로드
- `push`, `pull`, `checkout`, `clone`, `merge` 사용

프롬프트 목록 기능은 별도의 `feature/list` 브랜치에서 구현한 후 `main` 브랜치에 병합했습니다.

## 보너스 기능

### JSON 저장 및 불러오기

프롬프트 데이터를 JSON 파일에 저장하여 프로그램 종료 후에도 데이터를 유지합니다.

### Markdown 내보내기

등록된 전체 프롬프트를 카테고리별 Markdown 문서로 정리하여 `exports` 폴더에 저장합니다.
